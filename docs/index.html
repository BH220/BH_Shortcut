원격 데스크톱 접속 정보와 실행 파일을 단축명으로 등록해 두고 한 목록에서 관리합니다. 목록은 JSON 파일로 내보내거나 로그인한 뒤 서버와 주고받습니다.

무엇을 하나

여기저기 흩어진 접속 정보와 실행 경로를 한 목록에서 찾고, 고치고, 옮깁니다.

목록 관리

구분, 단축명, 프로그램명을 한눈에 보는 목록에서 새 명령을 추가하고 저장·삭제합니다.

원격 연결

주소, 포트, 가로·세로 크기를 등록해 원격 데스크톱 접속 정보를 단축명으로 보관합니다.

프로그램 실행

실행 파일을 골라 전체 경로를 등록합니다. 프로그램명을 비워 두면 파일명으로 채워집니다.

오프라인 업로드 · 다운로드

목록을 JSON 파일로 내보내고, 다른 PC에서 그 파일을 골라 그대로 들여옵니다.

온라인 업로드 · 다운로드

로그인한 뒤 서버에 목록을 올리고 받아 옵니다. 로그인 정보는 화면에 표시되고 링크 하나로 로그아웃합니다.

DB 직접 접근 없음

앱은 데이터베이스에 직접 붙지 않습니다. 모든 조회와 저장은 인증된 서버 API를 통해서만 이뤄집니다.

설치 방법

처음 한 번만 확인하면 됩니다.

1. Windows에 설치

  1. Windows용 설치하기를 눌러 설치 파일을 받고 압축을 풉니다.
  2. install.exe를 실행합니다. "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행을 누릅니다.
  3. 설치가 끝나면 바탕 화면이나 시작 메뉴의 BH Shortcut을 실행합니다.

2. 단축명 등록

  1. 목록 오른쪽 위 새 명령을 누르고 단축명과 프로그램명을 적습니다.
  2. 구분에서 원격연결을 고르면 주소·포트·가로·세로 크기를, 프로그램을 고르면 찾아보기로 실행 파일을 지정합니다.
  3. 저장을 누르면 목록에 들어갑니다. 목록에서 항목을 고르면 같은 자리에서 고치거나 삭제할 수 있습니다.

3. 서버 주소와 로그인

온라인 업로드·다운로드를 고르면 로그인 창이 열립니다. 관리자에게 받은 서버 주소는 %ProgramData%\BH Soft\BH Shortcut\settings\ServerSetting.json에 저장되며, 로그인하면 다운로드 버튼 옆에 [아이디(이름)]이 표시됩니다. 다른 기기에서 이미 로그인 중이면 확인을 거쳐 이 기기로 세션을 옮깁니다.

소스에서 빌드

.NET 8 SDK가 있으면 명령 한 줄로 빌드됩니다. Visual Studio 2022에서는 BH_Shortcut.sln을 열고 BH_Shortcut을 시작 프로젝트로 실행합니다.

git clone https://github.com/BH220/BH_Shortcut.git
cd BH_Shortcut
dotnet build BH_Shortcut.sln -c Release

BH_Shortcut.Core공통 모듈. 설정 파일, 세션 모델, 로그, 경로·문자열 유틸리티
